Install the SafeHome lamp software

This page puts the lamp's software onto the lamp board. You only need to do it once, or again when a new version is released. You don't need to install anything else on your computer.

Before you start, you need:
  • The lamp board, plugged into this computer with a USB cable that can carry data.
  • The Google Chrome or Microsoft Edge browser. Other browsers, such as Firefox, can't do this step.
  • Nothing else using the lamp board. Close any other program that shows the board, such as the Arduino IDE's Serial Monitor.

Steps

  1. Make sure the lamp board is plugged in.
  2. Click the blue Install SafeHome lamp button below.
  3. A window appears listing the boards it can find. Click the one that shows USB-Enhanced-SERIAL CH9102 or USB Serial, then click Connect. If you see more than one, unplug the board and see which name disappears.
  4. Click Install. Wait for the progress bar to finish. It takes about 30 seconds.
  5. When it says Installation complete, unplug the board and plug it in again.
This browser can't install the software. Open this page in Google Chrome or Microsoft Edge. This page must be opened from its web address, not from a file on the computer.
What happens next: the lamp board starts in setup mode and creates a Wi-Fi network called SafeHome-Setup. Follow Step 5 of the setup guide to connect it to your home Wi-Fi.

If the install fails, unplug the board, plug it back in, and try again. Still stuck? See the troubleshooting table in the setup guide.
